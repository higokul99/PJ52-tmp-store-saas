# E-Commerce Platform

The application is fully responsive and optimized for mobile, tablet, laptop, and desktop devices, providing a consistent and user-friendly experience across different screen sizes.

## Project Structure
- **/frontend**: React + Vite application for the storefront and merchant dashboards.
- **/backend**: Laravel API application for managing stores, products, orders, and authentication.

## Getting Started
1. Run `composer install` in the backend directory.
2. Run `npm install` in the frontend directory.
3. Configure the `.env` file in the backend to point to your database.
4. Run `php artisan migrate` to set up the database tables.
5. Use `php artisan serve` and `npm run dev` to start the development servers.
